# Study Buddy

Flashcard/quiz app with class-wide struggle heatmap.

## Setup (do this after cloning)

1. Clone the repo:
   git clone https://github.com/charlestran2006/study-buddy.git

2. Go into the backend folder:
   cd study-buddy/backend

3. Install dependencies:
   npm install

4. You'll need a `.env` file with database credentials (not committed
   to git — contains secrets). This doesn't exist yet — will be added
   once the database is set up.

More setup steps will be added here as the project grows.
